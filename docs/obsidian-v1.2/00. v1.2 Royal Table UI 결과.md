# 🎨 포커 디펜스 v1.2 Royal Table UI 결과

> 게임 규칙은 유지하면서 화면 겹침을 제거하고 카드 테이블의 시각적 완성도와 전투 판독성을 높였다.

## 완성된 UI

- [x] 우측 패널을 상태·경제·군단·컨트롤·무늬 스킬·유물·도움말의 7개 고정 구획으로 분리
- [x] 모든 패널 구획의 경계·거터를 단일 레이아웃 데이터로 관리
- [x] 보스 HUD를 필드 위에서 상태 구획 안으로 이동
- [x] 긴 유닛 정보·대기 유닛·유물 목록의 줄바꿈 영역 제한
- [x] 카드 획득 안내문을 296px 고정 폭으로 제한해 우측 패널 침범 방지
- [x] 준비/전투 컨트롤을 같은 구획에서 교체해 수직 공간 고정
- [x] 카드 전용 하단 트레이와 카드 그림자·내부 테두리·양쪽 코너 표기 추가
- [x] 홀드 카드의 상승·금색 테두리·LOCKED 상태 강화
- [x] 필드 타일의 깊이, 경로 방향 마커, 스폰 포털, 중앙 워터마크 추가
- [x] 유닛에 그림자·색상 헤일로·선택 링 추가
- [x] 일반·고속·방어·재생·분열·보스 적의 실루엣과 문장 차별화
- [x] 적 HP 바는 피해를 입었거나 보스일 때만 표시해 전투 시각 노이즈 감소
- [x] 버튼의 그림자·상단 하이라이트·명도 기반 글자색·호버 피드백 개선
- [x] 메인 화면에 카드 무늬 워터마크와 Royal Table 프레이밍 추가

## 겹침 방지 기준

`1280×720` 기준 고정 캔버스를 7개 패널 구획으로 나누고 각 구획 사이에 최소 8px 거터를 둔다. 보스 HUD는 상태 구획 내부에 포함한다. 화면 크기가 작아질 때 Phaser `FIT`이 전체 캔버스를 비율 유지 축소하므로 내부 좌표 관계는 변하지 않는다.
