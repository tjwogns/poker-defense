# UI 간소화 — v2.9.2 릴리스 기록 (2026-09-08)

## 요청과 범위

전체 난이도는 쉽다는 사용자 피드백이 있으나 조정은 보류한다. 이번 작업은 기존 UI에서 미래 웨이브 예고와 불필요한 상시 설명을 제거하는 편집이며, 새로운 디자인/메뉴/게임 시스템을 만들지 않는다.

## 현재 화면 점검

1. 모바일 준비 화면: 전장과 손패 사이의 다음 웨이브 카드가 종류·수량·힌트·보스까지 거리를 동시에 표시한다. 리롤 자동 판단 바도 패/확정 행동과 시선을 나눈다. 현재 패→유닛·문양 효과와 큰 확정 버튼은 유지할 장점이다.
2. 데스크톱 준비 화면: 예고, 행동 안내, 강화, 빈 빌드가 모두 테두리 상자로 나뉜다. 다음 웨이브 이름과 수량 간격도 좁다. 예고와 빈 빌드 장식을 제거하고 현재 행동과 강화 접근은 보존한다.

현재 실행에서 캡처/검수한 원본: `/tmp/poker-ui-audit/01-before-preparation.png`, `/tmp/poker-ui-audit/02-before-desktop.png`.

## 승인된 변경

- 미래 종류·수량·대응힌트·보스까지·스폰 순서 예고 제거.
- 리롤 자동 판단 패널 제거, 현재 패/홀드 기준 확률 상세 버튼 유지.
- 라이프 헤더의 누적 탈출 수를 제거, 결산/실제 피해 기록은 유지.
- 예고 슬롯은 필요할 때의 실제 결과/현재 보스/코치 정보만 표시. 빈 예고 테두리를 남기지 않는다.
- 빈 빌드 안내 제거. 문양·전술·내기·유닛 상세·핵심 조작 유지.

## 검증 기준과 한계

모바일/데스크톱, 한국어/영어, 준비/전투 상태에서 미래 예고가 사라지고 핵심 조작·확률창·현재 보스 HP가 유지되는지 확인한다. 레이아웃 및 상태별 자동 테스트와 빌드를 실행한다. 화면 캡처만으로 스크린리더/전체 키보드 접근성 또는 실제 모든 모바일 기기의 대응을 보장하지 않는다. 정보 예고 제거는 사전 판단에 영향을 주지만 수치·RNG·경제·승패를 보정하지 않는다.
