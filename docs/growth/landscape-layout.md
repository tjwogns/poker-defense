# 가로 전장 레이아웃 정리

> 릴리스 갱신: v2.9.6(2026-09-10) 사용자 커밋·배포 승인으로 정식 공개 대상에 포함. 아래 ‘배포 없음’은 구현 당시 기록이다. 전체 릴리스 검증 58파일498테스트 및 빌드 통과.

## 목적과 범위

사용자 피드백: 가로 화면에서 전장 오른쪽이 비어 있으며 패 선택을 오른쪽으로 옮기거나 맵을 더 크게 보고 싶다.

1280×720 논리 화면을 왼쪽 전장·오른쪽 조작 영역으로 재배치한다. 세로 레이아웃과 게임 수치, 정식·실험 맵의 경로는 유지한다. 준비/배치/전투 상태 사이 전장 위치나 크기가 바뀌지 않는다. 쌍정원 선택 제외도 보존한다.

## 승인한 배치

- 전장: (16,84), 표시 타일 50px, 850×600. 이전 714×504 대비 가로·세로 약 19% 확대.
- 코어 타일은 42px를 유지하고 표시 배율만 50/42로 바꾼다. 적 속도·공격 사거리 자체는 변경하지 않는다.
- 오른쪽 영역: x888~1264. 현재 상태/보스, 손패 5장, 족보 요약, 확률·문양 선택, 교환·확정·시작, 강화, 보유 효과, 보조 버튼 순서.
- 처음 실행 안내도 오른쪽으로 이동하여 경로 위를 가리지 않는다.
- 카드·행동·강화 영역은 서로 겹치지 않게 유지하고, 전투 중 강화·배속·일시정지 기능을 보존한다.

## 검증 기준

- 렌더·사거리·유닛·투사체·피해 숫자·추천·클릭 좌표의 표시 변환 일치.
- 5장 홀드/교환/확정/배치/전투 시작의 실제 브라우저 확인.
- 준비와 전투 전장 크기 동일, 보스 상태와 유닛 상세의 우측 UI 충돌 없음.
- PC 가로와 모바일 세로 회귀 확인. 작은 가로 화면은 축소에 따른 가독성도 확인.
- 전체 테스트·빌드 및 독립 테스트. 커밋·버전 변경·배포는 요청 범위에 포함하지 않음.

## 검증 결과

- 구현 완료. 전체 테스트 58파일·498개, 빌드 및 diff 검사 통과. 독립 테스터도 전체 명령 재실행 통과.
- 실제 좌표 함수의 타일 중심 왕복 1,632건과 바깥 경계 32건 확인. 코어 42px와 세로 계산식 유지.
- PC 1280×720: 실험 회랑에서 홀드/교환/확정/추천 배치/전투/일시정지/유닛 상세 및 사거리 표시 확인.
- 브라우저에서 배치·시작 상태의 이전 교환 버튼 잔류를 발견해 수정. 최종 빌드 정식 교차로에서 배치 안내와 전투 시작 버튼이 각각 단독 표시됨을 확인.
- 영어 최종 보스 HUD와 전투 중 강화 확인: 골드100→65, 강화Lv0→1. 보스 설명·카드·행동·강화 겹침 없음.
- 844×390 작은 가로 화면 잘림 없음. 전체 캔버스 축소 특성상 보조 글자는 작아지는 한계가 남는다.
- 390×844 세로 화면은 기존 전장 위/카드 아래 배치를 유지함을 확인.
- 준비·전투 간 전장 표시 크기는 850×600으로 동일. 실제 경로/밸런스 변경 없음.
- 기존 미커밋 변경 보존, 버전·커밋·배포 없음. 로컬 실험 진입: `http://127.0.0.1:4174/?lang=ko&experiment=battlefields`.
