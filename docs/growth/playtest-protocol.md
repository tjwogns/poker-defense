# 실제 신규 플레이어 첫 원정 검증

상태: 실행 준비 문서. 참여자 모집·연락·사례비 지출·실제 사람 테스트는 아직 하지 않았다. 코드/봇 테스트를 인간 플레이 결과로 대체하지 않는다.

## 목적과 표본

첫 안내와 내기 설명에서 막히는 지점, 카드→군단 이해를 탐색한다. 장기 재방문·난이도·세계 시장성을 판정하는 실험은 아니다. 처음 접하는 성인 5~8명으로 탐색적 검증을 시작하고 포커/모바일 웹게임 경험을 구분한다. 기존 플레이어·개발/QA·fixture는 별도 집단이다.

개인 브라우저 기록을 지우지 않는다. 참여자가 동의한 테스트용 프로필을 쓰고 이름·계정·연락처·음성은 수집하지 않는다. 익명 번호/기기 유형/경험 여부/관찰 메모면 충분하다. 화면 녹화는 별도 동의, 외부 모집·메시지·비용은 별도 승인 대상이다.

## 10~15분 진행

1. 0~2분: “처음 보는 웹게임을 평소처럼 살펴봐 주세요. 사람을 평가하는 것이 아니라 게임의 이해하기 어려운 부분을 찾습니다. 언제든 멈춰도 됩니다.” 홀드·교환·내기·배치 정답을 먼저 가르치지 않는다.
2. 2~10분: 자유 플레이. 첫 메뉴 선택, 내기 선택/건너뛰기, 카드→확정→배치→전투의 순서와 시간을 기록한다. 문양/배치의 반복 클릭, 도감 사용, 도움 요청과 중단 직전 화면을 관찰한다. HOLD/교환은 선택 행동이지 필수 통과 단계가 아니다.
3. 막힌 경우: “지금 무엇을 하려고 하셨나요?”, “어떤 일이 일어날 것으로 예상하셨나요?” 도움을 요청하면 제공하되 그 이후는 도움받은 진행으로 표시한다. 특정 버튼을 누르도록 유도하지 않는다.
4. 10~15분: “카드로 무엇을 만들었다고 생각하세요?”, “바꾸거나 그대로 확정한 이유는?”, “가장 헷갈렸던 순간은?”, “지금 무엇을 하고 싶으세요? 그만해도 괜찮습니다.”
5. 결과 화면에 자연스럽게 도달한 경우만 재도전/메뉴/공유의 실제 선택을 관찰한다. 테스트를 위해 패배나 재도전을 강제하지 않는다.

## 해석

참여자의 설명과 행동을 함께 보고 족보 암기를 요구하지 않는다. 도움 없이/도움 후 첫 전투 시작을 분리한다. “5명 중 2명”처럼 원수를 쓰고 전체 이용자 비율로 일반화하지 않는다. 수정 전 비교가 없으면 이번 변경의 인과효과를 주장하지 않는다.

신규 사용자는 일일 개인 기록이 없으므로 이 세션에서 개인 최고 표시의 효과는 검증할 수 없다. 실제 기록이 생긴 참여자의 후속 방문으로 분리한다. 재도전 의향/실제 클릭/다음 날 재방문은 서로 다르다.

## 세션 기록 양식

- 익명 세션 번호 / 날짜 / 코드 버전 또는 커밋 / 기기·뷰포트 / 언어:
- 첫 방문 여부 / 포커 경험 / 모바일 웹게임 경험 / QA 여부:
- 첫 선택 / 내기 선택 또는 건너뛰기:
- 확정·배치·전투 시작 도달 시각(관측 못 함은 명시):
- 도움 없이 진행한 지점 / 도움 내용과 시각:
- 혼란·반복 클릭·예상과 다른 결과의 화면과 발화 요약:
- 카드→유닛 이해의 설명 및 행동 근거:
- 자발적 종료·재도전·메뉴 선택 / 관측 못 한 항목:
- 진행자의 유도·기술 장애 등 교란 요인:

종합 결과에는 반복된 문제, 잘 이해한 부분, 관측하지 못한 항목, 다음 개선 후보 1~2개를 함께 남긴다. 빈 양식은 완료된 테스트 결과가 아니다.
