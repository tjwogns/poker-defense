# 세계적 인기 웹게임을 향한 개선 계획

## v2.9.6 다음 우선순위 (2026-09-10)

가로 확대·우측 손패 및 격리된 전장 비교 실험을 공개한다. 선택은 교차로·회랑·나선이며 쌍정원은 제외했다. 58파일498테스트와 독립 빌드 검증 통과. 다음은 같은 첫 패로 전장별 초반 10라운드를 비교하고 배치 선택 차이·지루한 구간·자발적 재도전 이유를 기록하는 소규모 사용자 테스트다. 순서 효과를 줄이기 위해 참가자별 전장 순서를 바꾼다. 재미 개선은 미입증이며 새 성장 요소·난도 수치 조정은 결과를 보고 선택한다.

## 목표와 운영 원칙

사용자 목표: **1등 웹 게임이 되기 위해 부족한 점과 추가할 점을 찾아보고, 참고하고, 고민하며 작업한다.** 이 목표는 아래 한 번의 패치로 축소하거나 완료 처리하지 않는다. 순위나 흥행은 보장할 수 없으며, 이용자 경험과 관측 가능한 성과로 반복 검증한다.

- 시작 기준: 공개 v2.9.4, `a620350`, 깨끗한 작업 트리, 52파일450테스트.
- 사용자 제약 유지: 복잡한 상시 UI/미래 웨이브 예고를 되살리지 않는다. 난이도 수치 변경 보류. 기존 경로/전장 크기/일반 탈출 −1/보스 탈출 패배/최종전 무제한 유지.
- 새 유료 작업·플랫폼 계약·공개 모집은 별도 승인. 버전·커밋·배포도 별도 요청 전에는 실행하지 않는다.
- 유료 출석 유도, 강제 광고, 손실 회피를 악용하는 보상 압박 대신 게임 자체의 재미와 명확한 선택을 우선한다.

## 외부 참고 (2026-09-08 확인)

- [Poki Engagement](https://developers.poki.com/guide/engagement): 첫 세션, 빠르고 만족스러운 반복, 명확한 목표, 연속적인 행동을 강조. 우리 게임에 그대로 복사할 공식이 아니라 첫 3분을 점검할 근거다.
- [Poki Playtesting](https://sdk.poki.com/playtesting): 플레이 시간과 초반 이해를 실제 플레이 테스트로 확인하도록 권장.
- [CrazyGames Basic Launch](https://docs.crazygames.com/resources/basic-launch-metrics/): 평균 플레이 시간, 다음 날 재방문, 1분 이상 플레이 전환을 별개로 본다. 가이드 예시의 10분/10~15%/80%는 플랫폼 참고 수치이며 우리 게임의 실측값이나 성공 보장이 아니다.
- [CrazyGames Gameplay](https://docs.crazygames.com/requirements/gameplay/): 빠른 게임 진입과 모바일 조작을 확인할 배포 적합성 참고.

## 현재 증거와 한계

기획·데이터 분석을 병렬 수행했다. 이미 족보→유닛/문양/전술, 합성/유물/덱개조, 왕관/일일도전/발견 기록이 있어 비슷한 성장 시스템을 바로 추가할 근거는 부족하다.

- 첫 실행 코치 R3는 모바일에 없는 `우측 BUILD`를 지시한다. R2/R3 안내가 확정/대표문양/배치 대기 상태보다 라운드 번호를 우선한다.
- 일반 결과 화면 `같은 조건으로 다시 도전`은 실제 새 seed 생성과 일치하지 않는다. 일일 모드만 같은 seed다.
- 실제 원정 진입은 카드 조작 전에 왕실 내기를 선택/건너뛴다. 선택적 보너스라는 설명을 명확히 할 여지가 있지만, 이것이 실제 이탈의 원인이라는 인간 데이터는 없다.
- 로컬 D1 이벤트 0건은 개발 DB 결과이며 운영 데이터 0건이 아니다. 9/5 문서 스냅샷 19세션/시작14/종료2, D1 2/7은 과거 버전·극소 표본이다. 9/6의4판은 독립 이용자4명으로 볼 수 없다.
- 기존 집계는 CLASSIC 승률과 버전 혼합 퍼널, 미성숙/아무 이벤트 재방문 코호트가 섞여 현재 LIFE 성과로 단정할 수 없다. 봇 시뮬레이션은 인간 통계와 합치지 않는다.

## 우선순위와 완료 증거

1. **첫 이해와 재도전 신뢰** — 로컬 구현·독립 검증 완료. R1~R3의 현재 가능한 행동을 안내하고, 모달 뒤 코치 중복을 없애며, 재도전 문구를 실제 모드와 맞췄다. 52파일455테스트 및 한/영 모바일 상태 전이 실제 클릭을 확인했다. [증거와 한계](first-session/README.md).
2. **신뢰할 수 있는 성장 측정** — 로컬 구현·독립 재검증 완료. [LIFE 코호트 도구](../analytics-life-cohorts.md)는 버전/LIFE/왕관 시작 코호트로 첫 전투 도달·단계별 누락·완결일 기준 다음날 실제 재시작을 집계한다. 실제 DB 마이그레이션을 적용한 로컬 합성 데이터로 검증하며 원격 조회는 명시적으로 분리했다. 중간 이탈 후 계속한 런의 분류, 잘못된 응답 오류의 원문 노출 가능성을 독립 검증에서 발견하고 수정·재검증했다. 실제 운영 지표는 아직 조회하지 않았다.
3. **첫 원정의 재미와 선택 밀도** — 실제 신규 플레이어 관찰과 1~3라운드 행동/대기 시간을 근거로 판단. 카드로 군단을 만든다는 강점을 빨리 경험시키되 결과 조작·기존 난도 무단 변경은 하지 않는다.
4. **이탈 후 돌아올 이유/진행 보호** — 왕관 목표는 이미 표시되므로 중복 추가하지 않았다. 기존 오늘의 도전 버튼에 도전 날짜가 일치하는 기기 내 최고 기록을 두 줄로 표시하도록 구현했다. 공유 도전 수락 문구와 버튼 크기·동작은 유지했다. 기록 없음/0점/어제 기록/큰 점수 자동 테스트, 한영 360×740 시각 검증과 실제 버튼 클릭을 확인했다. 런 저장은 [별도 안전 설계 후보](resume-design.md)이며 아직 지원하지 않는다.
5. **배포·발견 가능성** — 초기 다운로드/콜드 로딩/안전 영역/브라우저 호환성과 포털 요구사항 격차를 확인. 플랫폼 제출·계약·광고·SDK/동의 변경은 승인 없이 진행하지 않는다.
6. **실제 시장 검증** — 외부 독립 플레이어 표본, 버전별 세션 질·재방문·추천 의향을 확인해 앞 단계의 효과를 검증. 코드 테스트만으로 글로벌 경쟁력/1등 달성을 주장하지 않는다.

## 이번 목표 턴 상태

- 저장소·공식 자료·측정 한계·브라우저 증거를 확보하고 우선순위에 따라 로컬 개선 중. 실제 이용자 성장이나 시장 순위를 입증한 상태는 아니다.
- 목표 전체는 미달성/활성 상태. 첫 구현의 완료가 전체 목표의 완료를 의미하지 않는다.
- 이번 로컬 변경 최종 검증: 54파일463테스트, 타입 검사/빌드/diff 검사, 독립 재검증 통과. 원격 조회·유료 작업·버전 변경·커밋·배포 없음. 다음 기술 점검은 메뉴 화면 크기 전환 재현, 다음 제품 검증은 실제 신규 플레이어 첫 원정 관찰이다.
- 후속 진척: [화면 크기 전환](viewport/README.md)의 좌표 불일치와 이중 중앙 정렬을 재현·수정했다. 원정 상태 고정과 안전한 메뉴 재배치, 모달 유지 후 복귀를 확인했다. 누적 55파일469테스트/빌드/독립 재검증 통과. [신규 플레이어 검증 절차](playtest-protocol.md)를 준비했으며 실제 모집·참여자 테스트는 아직 실행하지 않았다. 배포·유료 작업 없음, 전체 시장 목표는 여전히 미달성이다.
- 이후 사용자 승인으로 v2.9.5 `0d49377` 공개 배포 완료. 2026-09-09 KST [첫 운영 집계](v2.9.5-first-observation.md)는 해당 버전 시작 0런으로, 아직 이용자 경험 효과를 판단할 수 없다. 한국 날짜와 UTC 마감 차이로 미래 관측 경계가 허용되는 분석 도구 문제를 합성 데이터로 재현해 보완한다. 배포 완료를 실제 시장 목표 달성으로 간주하지 않는다.
