# 전장 다양성 실험

> 릴리스 갱신: v2.9.6(2026-09-10) 사용자 승인으로 배포 대상에 포함. 아래 단계별 ‘커밋·배포 없음’은 당시 상태다. 정식 주소에 `?experiment=battlefields`로 진입하며 정식 기록은 격리한다.

## 현행 선택 목록

사용자 요청으로 쌍정원을 우선 제외했다. 현재 선택 가능한 전장은 기존 교차로·평행 회랑·안쪽 나선이며 대체 전장은 추가하지 않았다. 쌍정원 직접 URL도 교차로로 돌아간다. 아래 쌍정원 설계·측정은 과거 실험 기록으로 보존한다. 모바일 마지막 카드는 가운데 정렬하고 PC는 3개 카드를 중앙 정렬한다.

## 사용자 피드백과 범위

“족보를 뽑는 맛은 재미있지만 같은 트랙을 계속 막는 부분이 반복 플레이에서 루즈하다.” 사용자는 기존 전장을 보존하고 별도 실험 모드에서 전장 3종을 비교하는 방향을 승인했다.

첫 목표는 카드로 만든 병력을 **다르게 배치할 이유**를 만드는 것이다. 배경만 바꾸거나 적 체력을 올리는 것은 이 피드백의 해결로 보지 않는다. 재미 개선 자체는 실제 플레이 비교로 검증해야 한다.

- 정식 cross-road는 그대로 두고 비교 기준으로 포함한다.
- 새 전장은 평행 회랑(근접한 다중 구간), 쌍정원(앞뒤 방어 분산), 안쪽 나선(외곽 공격/출구 마무리) 3종이다.
- 그리드 17×12, 렌더 크기, 적/유닛 수치, 골드, 족보, 웨이브, 승패 규칙은 그대로 유지한다.
- 각 원정은 한 전장으로 고정한다. 자동 교체, 분기 이동, 새 특수 규칙/보상, 미래 웨이브 예고는 추가하지 않는다.
- 실험 전용 진입점 `?experiment=battlefields`에서 실제 경로 도식과 설명을 보고 선택한다. 정식 메뉴에 새 상시 패널을 넣지 않는다.
- 같은 seed로 전장을 바꿔 비교한다. 같은 seed라도 교환·배치·선택이 달라지면 결과는 달라질 수 있다.

## 격리와 기존 효과

실험은 정식 기록·왕관·일일 순위·업적·히든 발견·튜토리얼 완료와 운영 분석에 반영하지 않는다. 기존 프로필은 읽기만 하고 실험 중 저장은 메모리 사본에 한정한다. 점수 제출과 정식 결과 공유는 차단한다.

교차로 표식 유물이 조용히 무효화되지 않도록 모든 실험 경로가 중앙 (8,5)를 지나게 한다. 같은 중앙 위치/1.25타일 반경/기존 피해 배율을 사용하고 실험 안내에 명시한다. 사분면 전술도 기존 그리드 좌표 기준을 유지한다. 경로 변화에 따른 효과 가치 차이는 별도 측정한다.

## 비교 기준

기존 cross-road: 이동 80타일(3,360px), 직선 12구간, 고유 경로 57칸, 배치 60칸. 정적 사거리 3.5 기준 평균 접촉 길이 22.649타일, 최대 29.730타일. 이는 경로와 공격 원의 교집합을 통과 횟수만큼 합산한 값이지 DPS나 공격 횟수가 아니다.

새 전장의 이동 길이, 배치 가능 칸, 사거리별 접촉 기회, 추천 위치, 첫 접촉까지 이동과 무접촉 구간을 비교한다. 같은 길이라고 같은 난도라고 부르지 않는다. 수치가 달라도 차이를 숨기기 위한 추가 밸런스 조정은 이번 범위에서 하지 않는다.

## 수용 기준

- 유효한 그리드 내부 직교 경로, 0길이/순간이동/경로 위 배치 없음.
- 실제 경로·배치 가능 표시·클릭 판정·추천·입출구 표시 일치.
- 끝에서 clamp 및 탈출/보스 패배, 같은 seed 손패, 정식 기본 맵 불변.
- 프로필 저장·운영 분석·랭킹의 실험 격리와 재시작/나가기 일관성.
- 모바일/데스크톱 전장 선택·실제 배치·전투를 브라우저로 검증.
- 3종이 단순 회전/복제에 그치지 않고 접촉 분포와 배치 선택을 다르게 제공.

현재 상태: 구현 및 자동·브라우저 검증 완료. 실제 반복 플레이 선호 비교는 남아 있다. 버전 변경·커밋·배포·유료 자산 생성은 범위에 포함하지 않는다. 기존 UTC 분석 도구 미커밋 수정은 보존한다.

## 플레이 비교 질문

1. 이번 전장에서 유닛 위치를 정할 때 무엇을 고려했나요?
2. 앞 전장과 같은 행동을 반복한 부분, 다르게 해본 부분은 무엇인가요?
3. 한 번 더 한다면 어떤 전장을 고르겠어요? 고르지 않아도 괜찮습니다. 이유도 알려주세요.

전장별 선호를 단순히 더 쉬웠거나 좋은 패가 나온 것과 구분한다. 모든 원정을 끝낼 필요 없이 같은 패 묶음의 초반 몇 라운드를 비교하고, 한 번의 선호를 장기 반복성 해결로 일반화하지 않는다.

## 2차 간격 정돈 (2026-09-09)

사용자가 길 사이 간격과 전체 완성도를 지적했다. 픽셀 배율 문제가 아니라 80타일 조건에 맞춘 끝부분의 자투리 경로, 맵마다 다른 외곽 범위가 원인이었다. 80타일 고정 조건을 철회하고 규칙적인 기하를 우선한다.

- 신규 3맵 외곽 범위: 모두 x2~14, y1~9로 통일.
- 평행 회랑: y1/3/5/7/9의 같은 폭 5개 차선. 마지막 1칸 꺾임과 꼬리 제거.
- 쌍정원: x2~6 / x10~14의 동일 4×8 박스, y5 중앙 연결. 두 정원의 안쪽 중점에 입출구를 두고 오른쪽 자투리 길 제거.
- 안쪽 나선: 경로 중심 사이 2칸 간격, 같은 외곽 기준으로 축소·정렬.
- 선택 화면은 고정 ‘80’ 대신 실제 경로 길이를 표시한다. 정식 교차로·클래식, 적/유닛 수치는 바꾸지 않는다.
- 경로 길이 감소는 방어 시간 감소를 동반한다. 미관 개선을 동일 난도 유지로 표현하지 않으며 비교 실험의 제한으로 기록한다.
