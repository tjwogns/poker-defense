## 📌 현재 상태

- **v1.0 Royal Siege 구현 완료**
- 유닛 10종 · 적 6종 · 60라운드 · 보스 6회
- 동일 등급 3기 합성, 유물 6종, 일반/데일리 런, 점수, 업적 6종
- 첫 판 튜토리얼, Web Audio 효과음, 일시정지, 키보드 조작, 모바일 가로 모드 안내
- localStorage에 최고 점수·최고 라운드·승리·업적·설정·데일리 기록 저장
- Vitest **81개 통과**, TypeScript strict 및 Vite 빌드 통과
- Chrome E2E: 메뉴 → 튜토리얼 → 확정 → 배치 → 전투 → 유물 선택 통과
- v1.0 봇 100판: **클리어율 28%, 평균 R55.2**
