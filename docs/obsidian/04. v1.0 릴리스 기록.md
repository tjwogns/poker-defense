# 🚀 04. v1.0 Royal Siege 릴리스 기록

## 결과

포커 디펜스를 코어 MVP에서 반복 플레이 가능한 싱글플레이 제품으로 확장했다. 핵심 변화는 **합성으로 낮은 족보의 가치를 보존하고, 유물로 매 판의 전략을 다르게 만들며, 데일리 시드와 기록으로 재방문 이유를 제공한 것**이다.

- [x] 같은 등급 3기 합성
- [x] 보스 격파 후 유물 3지선다와 유물 6종

- [x] 일반 게임과 오늘의 도전

## 제품 판단

### 강점

- 카드 운, 교환 경제, 배치, 합성, 유물의 선택이 서로 연결된다.
- 같은 시드로 버그와 밸런스를 재현할 수 있다.
- 서버와 외부 에셋 없이 즉시 실행·공유할 수 있다.
- 짧은 튜토리얼과 기록 화면으로 첫 실행과 재방문 흐름이 생겼다.

### 공개 출시 전 남은 것

- 실제 사람 플레이 데이터
- 배포 도메인과 OG 공유 이미지
- 온라인 점수 제출의 치팅 방지 정책
- 사운드·이펙트 볼륨 세부 조절
- R55 난이도 절벽 완화

## 결정 이력

- 서버 리더보드는 v1.0에서 제외했다. 재미와 리텐션 루프를 먼저 검증한다.
- 이미지·음원 파일을 추가하지 않았다. 초기 로딩과 단일 파일 배포를 유지하기 위해 벡터 그래픽과 합성음을 사용한다.
- 데일리 유물 후보 RNG는 카드 RNG와 분리했다. 선택지 생성이 이후 카드 순서를 바꾸지 않게 하기 위함이다.
