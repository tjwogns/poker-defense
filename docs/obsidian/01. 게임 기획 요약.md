# 🎴 01. 게임 기획 요약

> **한 줄 설명:** 패를 설계해 유닛을 만들고, 3기 합성과 유물 빌드로 60라운드를 버티는 포커 로그라이트 디펜스.

## 🔁 코어 루프

```text
카드 5장 → 홀드 → 교환 → 족보 확정 → 유닛 배치/합성/강화
→ 웨이브 전투 → 생존 적 이월 → 10R마다 보스와 유물 선택 → 반복
```

- 패배: 필드 적이 현재 상한을 초과
- 승리: 60라운드 종료까지 상한을 지킴
- 일반 웨이브 30기, 10라운드마다 보스 1기 + 수행원 10기
- 하이카드도 유닛을 지급해 매 라운드 최소 성장을 보장

## 🃏 족보와 유닛

| 족보 | 유닛 | 역할 |
| --- | --- | --- |
| 하이카드 | 견습병 | 근거리 재료·필러 |
| 원페어 | 궁수 | 기본 원거리 |
| 투페어 | 쌍석궁병 | 빠른 연사 |
| 트리플 | 화염술사 | 소형 스플래시 |
| 스트레이트 | 저격수 | 장거리·방어 무시 |
| 플러시 | 빙결술사 | 슬로우 |
| 풀하우스 | 성기사 | 공격력 오라 |
| 포카드 | 드래곤 기수 | 대형 스플래시 |
| 스트레이트 플러시 | 대마법사 | 체인 라이트닝 |
| 로열 스트레이트 플러시 | 신룡 | 현재 HP 비례 피해 |

## 🔺 3기 합성

준비 단계에서 같은 등급 유닛 3기를 합치면 다음 등급 유닛 1기가 된다. 결과 유닛은 첫 재료 위치에 생성된다. 신룡은 최고 등급이라 합성할 수 없다.

합성은 하이카드와 원페어도 장기 자산으로 바꾸며, 30기 필드 상한에서 생기는 정체를 해소한다.

## 🏺 유물 빌드

| 유물 | 효과 |
| --- | --- |
| 왕가의 인장 | 모든 유닛 피해 +12% |
| 전쟁 금고 | 처치 골드 +25% |
| 복리 장부 | 이자 +50%, 이자 상한 +20G |
| 증축 허가증 | 필드 적 상한 +10 |
| 재빠른 손놀림 | 매 라운드 교환 2회 무료 |
| 소매 속 에이스 | 보스 라운드 족보 +1등급 |

R10·20·30·40·50을 마치면 미보유 유물 중 결정론적 3지선다가 나온다. 같은 시드의 선택지는 항상 동일하다.

## 💰 핵심 선택

- 유료 교환: 고족보를 노리는 고위험 성장
- 공격력 강화: 즉시 적용되는 확정 성장
- 이자 유지: 다음 라운드의 선택권 확보
- 유닛 판매: 합성 재료를 포기하고 긴급 자금 확보
- 유물 선택: 현재 빌드의 약점을 보완하거나 강점을 증폭

전투 중에는 판매·강화·배치·합성을 금지한다. 준비 단계의 결정을 전투 결과로 확인하는 구조다.

## 📅 게임 모드와 기록

- 일반 게임: 매 판 새로운 시드
- 오늘의 도전: 날짜별 고정 시드, 같은 날은 같은 카드·유물 선택지
- 점수: 처치 + 라운드 클리어 + 족보 + 승리 보너스
- 저장: 최고 점수, 최고 라운드, 플레이 수, 승리 수, 오늘의 최고점, 업적

## 🎯 플레이 경험 목표

- 첫 30초 안에 첫 유닛 배치
- 한 판 약 15~20분
- 매 보스 뒤 빌드 방향 전환
- 패배 직후 다른 교환·합성·유물 선택을 시험하고 싶은 명확한 복기 포인트 제공
