# 🚀 포커 디펜스 v1.1 Breakout 결과

> **현재 정의:** 카드로 유닛과 액티브 스킬을 동시에 만들고, 6종의 고유 보스를 공략해 60라운드를 지키는 포커 로그라이트 디펜스.

## 완성된 제품 가치

- 패의 **족보는 유닛**, 가장 강한 **무늬는 전투 스킬**이 된다.
- 동일 유닛 3기 합성, 유물 6종, 경제 선택이 매 판 다른 성장 경로를 만든다.
- 10라운드마다 이름·기믹·HP HUD가 있는 고유 보스가 등장한다.
- 일반 게임과 날짜 고정 데일리 도전을 제공한다.
- 친구의 데일리 링크를 열면 원래 날짜·시드를 그대로 플레이한다.
- 종료 결과를 텍스트로 공유하거나 1200×630 PNG 카드로 저장한다.
- 최근 20판을 브라우저에 보존하고 JSON으로 내보낸다.
- 외부 이미지·음원·서버 없이 단일 HTML로 배포할 수 있다.

- [x] 공유 텍스트·도전 링크·PNG 결과 카드
- [x] 프로필 v2·최근 20판·JSON 로그

## 제품 포지션

**“포커를 잘 만드는 게임”이 아니라 “매 라운드 패로 군단과 필살기를 설계하는 게임”**으로 구분한다. 짧은 카드 결정, 자동 전투의 결과 확인, 합성·유물의 장기 설계, 동일 시드 경쟁을 하나의 반복 구조로 묶었다.
