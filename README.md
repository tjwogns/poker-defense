# 포커 디펜스 (Poker Defense)

포커 족보로 유닛을 뽑아 순환 경로를 도는 적을 막는 웹 디펜스 게임.
스타크래프트 유즈맵 '포커 디펜스'의 웹 재해석. (기획안: Claude 아티팩트 "포커 디펜스 — 게임 기획안 v0.1")

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 코어 로직 단위 테스트 (vitest)
npm run sim -- 30  # 헤드리스 밸런스 시뮬레이션 30판
npm run build      # 타입체크 + 프로덕션 빌드 (dist/)
SINGLEFILE=1 npm run build  # 단일 HTML 파일 빌드 (배포/공유용)
node scripts/smoke.mjs      # E2E 스모크 (Chrome 필요, 프리뷰 서버 선행: npx vite preview --port 4173)
```

## 게임 규칙 요약

- 매 라운드 카드 5장 드로우 → 홀드 후 교환(무료 1회, 추가는 골드) → **족보 확정 = 그 등급의 유닛 획득** (하이카드도 최하급 유닛 지급)
- 유닛을 타일에 배치하면 자동 공격. 적은 죽을 때까지 사각 경로를 순환
- **필드의 적이 80마리를 넘으면 패배**, 60라운드를 버티면 승리. 10의 배수 라운드는 보스
- 골드 사용처: 추가 교환(도박) vs 전역 공격력 강화(확정) vs 유닛 판매/재배치

| 족보 | 유닛 | 특성 |
|---|---|---|
| 하이카드 | 견습병 | 근거리 필러 |
| 원페어 | 궁수 | 기본 원거리 |
| 투페어 | 쌍석궁병 | 연사 |
| 트리플 | 화염술사 | 소형 스플래시 |
| 스트레이트 | 저격수 | 장거리 · 방어 무시 |
| 플러시 | 빙결술사 | 슬로우 |
| 풀하우스 | 성기사 | 아군 공격력 오라 |
| 포카드 | 드래곤 기수 | 대형 스플래시 |
| 스트레이트 플러시 | 대마법사 | 체인 라이트닝 |
| 로열 스트레이트 플러시 | 신룡 | 현재 HP 비례 피해 |

## 구조

```
src/core/   순수 TS 게임 로직 — Phaser 의존성 0, 고정 틱(30/s) 결정론 시뮬레이션, 시드 RNG
            (cards/ 덱·족보판정, combat 전투, game 상태머신, balance 모든 수치)
src/game/   Phaser 3 렌더링/입력 — core 상태를 그리기만 한다
src/sim/    헤드리스 밸런싱 시뮬레이터 (core만 import)
tests/      vitest 단위 테스트 (core 전체)
```

밸런스 수치는 전부 `src/core/balance.ts` 한 파일에서 관리한다.
현재 튜닝 기준: 휴리스틱 봇 클리어율 ~23%, 평균 도달 ~R54 (`npm run sim`으로 재측정).
