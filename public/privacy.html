플레이 데이터 안내

익명 플레이 기록은 선택 사항입니다. 게임 메인 화면의 DATA 버튼에서 언제든 허용하거나 중단할 수 있습니다.

기록하는 항목

게임 시작·재도전, 튜토리얼 완료 여부, 주요 라운드 도달, 보스 조우·처치·생존 여부와 남은 HP 비율, 확정한 족보 등급, 유닛 합성, 유물 선택, 종료 결과와 플레이 시간입니다. 같은 브라우저의 재방문을 집계하기 위한 무작위 방문 ID와 페이지·게임 단위 무작위 ID를 사용합니다.

기록하지 않는 항목

이름, 이메일, 연락처, 카드의 실제 내용, 계정 정보와 광고 식별자는 이벤트 데이터에 포함하지 않습니다.

저장과 전송

수집 서버가 설정되지 않은 빌드에서는 허용된 이벤트가 현재 브라우저에만 저장됩니다. 서버가 설정된 빌드에서는 동일한 이벤트 JSON과 게임 버전이 HTTPS로 전송될 수 있으며, 서버 운영 환경에는 일반적인 접속 기록이 남을 수 있습니다. 무작위 방문 ID는 서버에서 단방향 해시로 변환합니다. 분석 데이터베이스에는 원본 방문 ID와 IP 주소를 저장하지 않으며 원본 이벤트는 최대 90일 후 자동 삭제합니다. 브라우저에는 최근 이벤트 최대 500개만 보관합니다.

온라인 일일 랭킹

오늘의 도전 종료 후 이용자가 직접 랭킹 등록을 선택한 경우에만 날짜, 자동 생성된 지휘관 이름, 점수, 도달 라운드, 처치 수와 결과가 랭킹 서버로 전송됩니다. 이메일이나 직접 입력한 닉네임은 사용하지 않습니다. 같은 브라우저의 기록을 구분하는 무작위 ID는 서버에서 단방향 해시로 변환되며, 랭킹 화면에는 자동 생성 이름과 게임 결과만 공개됩니다.

삭제와 내보내기

DATA OFF로 변경하면 브라우저에 저장된 분석 이벤트가 삭제되고 이후 기록이 중단됩니다. 이미 전송된 이벤트는 개인 계정이나 연락처와 연결되지 않아 개별 사용자를 식별해 찾을 수 없으며 보존 기간이 끝나면 자동 삭제됩니다. LOG EXPORT 버튼으로 본인의 게임 기록과 허용된 분석 이벤트를 JSON 파일로 확인할 수 있습니다. 최고 점수 등 게임 진행 기록은 분석 동의와 별도로 브라우저에 저장됩니다.
